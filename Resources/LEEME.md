# Dejá el ícono acá

Guardá el PNG de 1024×1024 en esta carpeta con este nombre exacto:

    Resources/icono-1024.png

Avisame y lo miro. Si te gusta cómo quedó, corro el `sips`/`iconutil` de
docs/icono.md para generar `Velarium.icns`, y a partir de ahí
`Scripts/build-app.sh` lo mete solo en el bundle.

Si generaste varias versiones para comparar, ponelas como:

    Resources/icono-a.png    (la pantalla y el pulgar)
    Resources/icono-b.png    (el eco)
    Resources/icono-c.png    (el atril)
